# Gerenciador 98

Ícone original em geometria vetorial de pixel art, criado para a família 98. Paleta clássica, contorno escuro, luz superior esquerda e relevo consistente. Fontes editáveis SVG; recursos Android vetoriais/adaptativos. Não usa imagens de terceiros. Nome visível alterado; pacote, dados e assinatura preservados.
